Reproducibility (R compatibility)

Everything is computed in this browser; no data leave your computer.

Existing patients should tabulate all patients that have already been enrolled in any of the therapy arms. All covariates should be factors. There should be one factor called arm which specifies the therapy are to which the patient was admitted.

New patients should tabulate all patients to consider for allocation. All covariates should be the same factors as for Existing patients. If one of the columns contains a patient ID, specify the name of the column in 'Patient ID'.
